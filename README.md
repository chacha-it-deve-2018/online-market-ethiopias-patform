## 📌 Project Overview
**Ethio Online Market** is a dynamic, web-based e-commerce platform designed to facilitate online buying and selling in Ethiopia. It provides a user-friendly interface for customers to browse products and a secure administrative dashboard for managing inventory and orders.

---

## 🏗️ Core Architecture (SAD & OOP Principles)
This project was developed using **System Analysis and Design (SAD)** methodologies and **Object-Oriented Programming (OOP)** in PHP:

### 1. Database Management
Uses a relational MySQL database to store users, products, categories, and orders.


### 2. User Authentication
Secure login and registration system with session management to protect user data.

### 3. Responsive Design
The frontend is built to be mobile-friendly, ensuring customers can shop from any device.


---

## ⚙️ Key Features
* **Product Catalog:** Users can view products with detailed descriptions and prices.
* **Shopping Cart:** Add, remove, and update product quantities before checkout.
* **Search Functionality:** Quickly find items by name or category.
* **Admin Dashboard:** A private area for site owners to add new products or delete old ones.
* **Order Processing:** Simple workflow for customers to submit their purchase requests.

---

## 🛠️ Technology Stack
* **Backend:** PHP 8.x
* **Database:** MySQL (MariaDB)
* **Frontend:** HTML5, CSS3, JavaScript, and Bootstrap
* **Server/Hosting:** InfinityFree (Apache Server)
* **Development Environment:** XAMPP / VS Code

---

## 📂 Project Structure
* `/assets` - CSS, Images, and JS files.
* `/admin` - Files for the administrative dashboard.
* `db_connection.php` - Secure database connection configuration.
* `index.php` - The main landing page.

---

## 🚀 How to Run Locally
1. Clone the repository to your XAMPP `htdocs` folder.
2. Create a database named `ethio_market` in phpMyAdmin.
3. Import the `database.sql` file provided in this repo.
4. Access the site via `http://localhost/ethio-online-market`.
