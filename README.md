A dynamic, web-based e-commerce platform designed to facilitate seamless online shopping in Ethiopia. 🇪🇹

---

## 📌 Project Overview
**Ethio Online Market** is an e-commerce solution bridging the gap between local sellers and buyers. It provides a user-friendly interface for customers to browse products and a secure administrative dashboard for managing inventory and orders. 🛍️

## ✨ Key Features
* **👤 User Authentication:** Secure registration and login with session management.
* **🔢 Product Catalog:** Detailed product views with prices and descriptions.
* **🛒 Shopping Cart:** Real-time cart management (Add/Remove/Update items).
* **🔍 Advanced Search:** Easily find items by category or name.
* **🛡️ Admin Dashboard:** A powerful control panel to manage inventory, products, and user orders.
* **📱 Responsive UI:** Optimized design for mobile, tablet, and desktop devices.

---

## 🏗️ Technical Architecture
This project implements core **System Analysis and Design (SAD)** and **Object-Oriented Programming (OOP)** principles.

### 🛠️ Technology Stack
* **Backend:** PHP 8.x
* **Database:** MySQL (MariaDB)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Hosting:** InfinityFree (Apache Server)
* **Tools:** VS Code, XAMPP

## 🚀 How to Run Locally
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/chacha-it-deve-2018/online-market-ethiopias-platform.git](https://github.com/chacha-it-deve-2018/online-market-ethiopias-platform.git)
Setup Database:

Open phpMyAdmin in XAMPP.

Create a database named ethio_market.

Import the database.sql file from the repository.

Configure: Place the project folder in your htdocs directory.

Access: Open your browser and go to http://localhost/online-market-ethiopias-platform.
